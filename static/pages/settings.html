Log Retention

Automatic cleanup runs every 15 minutes. Rows are dropped once they exceed either limit below, whichever comes first -- the row cap is your backstop against a noisy or misbehaving source filling up storage faster than the day-based window would clear it.

Archival Storage

When enabled, logs that Retention above is about to delete are uploaded as a dated JSON Lines file first -- if the upload fails, that cycle's delete is skipped entirely rather than losing the rows. Credentials are encrypted at rest and never sent back to this page once saved.
SECLOG_MASTER_KEY is not set on the server -- a secret can't be saved until an administrator sets it (see README: Directory sync).
Host key is not verified -- only point this at a host on a trusted network. See ARCHITECTURE.md.

Agent Health

Checked every 5 minutes. An agent that goes this long without checking in fires a system alert (Settings → Alerts) -- once per episode, not repeatedly while still dark.
