Syslog Receiver

Lets firewalls, switches, and other devices that can't run the shipper send logs directly, over UDP and/or TCP port 514. Raw syslog has no per-message authentication -- industry-wide, not specific to SecLog -- so this is gated by a source-IP allowlist: nothing is accepted from an address that isn't listed below, even while enabled.
Enabling/disabling UDP or TCP here takes effect on the next server restart (this binds a network socket at startup). The allowlist below applies immediately, no restart needed.
Allowed source IPs/CIDRs, one per line (e.g. 10.0.0.0/8 or a single 192.168.1.50). Empty means nothing is accepted.
